# OASIS PoC 文書の取込みと方針差分

レビュー済みのPoC設計書・開発計画書v1.1を取り込む。アプリ実装・実機検証は未実施。

## 読む順序

1. この取込みメモ
2. リポジトリの既存資料：[要件定義書](../requirements.md)、[技術スタック](../tech-stack.md)
3. [PoC設計書1.1](oasis-poc-design.md)、[PoC開発計画書1.1](oasis-poc-plan.md)

PoC設計時に参照した会話内の要件定義書0.4・技術選定書0.1は、このPRには同梱しない。PoC文書にある`docs/source/`の参照先は未配置であり、開発開始プロンプトはそのまま実行せず、現行資料との方針を整理して参照先を確定する。文書内の「正本」「合意済み」は会話での文脈を指し、現在のリポジトリ全体の優先順位を変更しない。

## マージ前に整理する方針差分

比較対象のmain commit：`9620399bd309bf92cdd3d9c3ae43adc16aae1426`。

| 論点 | 既存のMVP資料 | 今回のPoC案 | 必要な整理 |
| --- | --- | --- | --- |
| 音声・呼び名 | 音声はMVP候補、明示開始・停止のみ。常時録音は対象外 | 明示有効化した音声待機と変更可能な呼び名を検証 | 常時収音と保存の区別、MVPか独立プローブかを確定 |
| STT | whisper.cpp | WhisperKitを第一候補 | 比較対象か採用変更かを確定 |
| 取得・保存前の確認 | 取り込み内容の確認、影響のある操作の実行前確認 | 指示に基づく記事取得・メモ保存を連続実行 | 確認UIと継続許可の扱いを統一 |
| 履歴と記憶 | 明示的なメモ、利用者が削除するまで保持 | 参照元要件は自動記憶・30日整理。PoCでは延期 | MVPの記憶・保持方針を確定 |
| 一括削除 | アプリ管理の利用者コンテンツを削除 | 会話全削除時も保存メモ・最小操作記録を保持 | 会話削除と全データ削除を分けて定義 |
| 検索 | SQLite FTS5をMVPに採用 | PoCは作成済みメモの部分一致 | PoCの限定とMVPへの移行条件を明記 |
| 外部AI | 将来の任意利用を記載 | 参照元要件では対象外 | 将来範囲の整合 |
| 構成・ツール | app/、docs/decisions/、SwiftFormatまたはSwiftLint | App/、docs/adr/、swift-format | 実装前に配置とツールを統一 |

上記の差分はこのPRでは解消・決定していない。既存のMVP方針を変更する実装は、採否を決めて関連文書を揃えてから行う。方針差に依存しない環境確認・候補の調査は進められる。
