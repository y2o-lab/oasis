# OASIS **Open Assistant System for Intelligent Support** あなたのそばで、理解し、覚え、行動する。 
自分だけのAIエージェントを、自分のデバイスに。 ## About OASISは、ジャービスのような「自分専用の相棒」を目指す、 
ローカルファーストのオープンソースAIエージェントです。 質問に答えるだけでなく、閲覧中の記事を要約する、メモを残す、 
過去の会話を踏まえて作業を手伝うなど、 日常のさまざまな場面でユーザーを支えることを目指します。 音声・テキスト・キーボードショートカットから、 
そのとき使いやすい方法で呼び出せる設計です。 画面上には、会話や処理の状態に合わせて変化する、 
もやもやした抽象的なビジュアルが相棒の存在を表します。 推論は端末内での実行を基本とし、 
外部AIサービスや専用サーバーに依存しない構成を目指します。 記憶や動作をユーザー自身が管理できることも大切にします。 
**OASISはプロジェクトの名前。相棒の呼び名は、あなたが決められます。** 
まずはmacOSから。将来的には、対応するデバイスや連携機能を広げていく予定です。
> 現在は設計・技術検証の準備段階です。記載内容は目指す体験を示すものであり、実装済みの機能ではありません。
